# Нейросетевой синтез многоплоскостных фазовых ДОЭ

Фазовый ДОЭ 128×128 (фаза от −π до π) рассчитывается так, чтобы при восстановлении
дифракцией Френеля (одно преобразование Фурье) на расстояниях 24,1 / 25,3 / 26,5 / 27,7 мм
фокусировались 4 заданных изображения. λ = 532 нм, пиксел ПВМС 10 мкм.

## Быстрый старт (Windows / Linux / macOS)

Нужен Python 3.10–3.12.

```bash
git clone https://github.com/tipoART619/Dzhungariki_special.git
cd Dzhungariki_special
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
# для NVIDIA GPU поставьте torch с CUDA по инструкции https://pytorch.org/get-started/locally/
python -m pytest tests
```

## Физическая модель (`doe/optics_np.py`, `doe/optics_torch.py`)

U_z(x,y) = e^{ikz}/(iλz) · e^{iπ(x²+y²)/(λz)} · FFT{ e^{iφ(ξ,η)} · e^{iπ(ξ²+η²)/(λz)} }

Внешние множители влияют только на фазу, поэтому восстановленное изображение = |FFT{e^{iφ}·chirp_z}|
(полная формула с физическими координатами — `fresnel_full`, тест подтверждает совпадение модулей).

Наблюдения о параметрах:

* **Условие дискретизации.** Чирп e^{iπr²/(λz)} дискретизирован без наложения при
  z ≥ NΔ²/λ = 24,06 мм. Первое расстояние (24,1 мм) лежит ровно на границе, т. е. параметры
  задачи подобраны корректно.
* **Шаг в плоскости изображения** λz/(NΔ): 10,0 / 10,5 / 11,0 / 11,5 мкм. Метрики сравниваются попиксельно 128×128.
* **Перекрёстные помехи.** Апертура 1,28 мм на ~25 мм: NA ≈ 0,026, глубина резкости λ/NA² ≈ 0,8 мм,
  а плоскости разнесены на 1,2 мм. В каждой плоскости виден расфокусированный фон от трёх других.
  Это физический предел: тот же ДОЭ на 1 плоскость даёт PCC ≈ 0,99, на 2 — ≈ 0,86, на 4 — ≈ 0,76.
* **SSIM.** На тёмном фоне SSIM очень чувствителен к малому спекл-шуму (даже при PCC = 0,99 для одной
  плоскости SSIM ≈ 0,23). Поэтому SSIM включён прямо в функцию потерь, в той же форме, в которой
  он считается при оценке (scikit-image, окно 7×7, нормировка амплитуды по 99,5-перцентилю).

## Нейросеть (`doe/model.py`)

Физически-информированная U-Net, обучение **без учителя** (готовые ДОЭ не нужны):

```
4 изображения t_j ─► t_j·e^{iφ_obj,j} ─► обратный Френель на z_j ─► V_j (поле в плоскости ДОЭ)
                     (φ_obj — обучаемая)                                    │
       вход U-Net: Re/Im V_j (8 каналов) + Re/Im ΣV_j (2 канала) ◄──────────┘
       U-Net ─► поправка (ΔRe, ΔIm) ─► φ = atan2(Im ΣV + ΔIm, Re ΣV + ΔRe) ∈ [−π, π]
       φ ─► прямой Френель на 4 z ─► |U_j| ─► loss = Σ_j (1−PCC) + MSE + 2·(1−SSIM)
```

* Преобразование Фурье сеть не учит: его выполняет известная физика (обратный пропагатор).
  Сеть учится исправлять суперпозиционную голограмму, т. е. делать то, на что итеративным методам нужны сотни итераций.
* Выходной слой инициализирован нулями: в начале обучения сеть выдаёт суперпозиционную голограмму, а не шум.
* `atan2` гарантирует диапазон [−π, π] без разрывов градиента при «перескоке» фазы.
* Синтез = один прямой проход (миллисекунды на GPU). Опционально `--refine N` — N шагов донастройки фазы
  на конкретных изображениях, если нужна максимальная точность.

**Данные** (`doe/dataset.py`): процедурный генератор (буквы/цифры латиницы и кириллицы, фигуры,
решётки, гауссовы пятна, комбинации, размытие); генерируется на лету, скачивать ничего не нужно.
Свои изображения (например, MNIST/EMNIST или тестовые изображения организаторов) подмешиваются
флагом `--extra-dir`. Валидационный/тестовый наборы фиксируются `scripts/make_dataset.py`.

## Классические методы для сравнения (`doe/baselines.py`)

* многоплоскостной **Гершберг–Сакстон**;
* **градиентная оптимизация фазы** (Adam) по той же функции потерь, с аналитическим градиентом
  через сопряжённый оператор Френеля (проверен конечными разностями в `tests/`).

Сравнение NN vs GS vs Adam по качеству и времени: `scripts/evaluate.py`.

## Рекомендации по обучению

* GPU, `--batch 16`, 20–30 тыс. шагов (`--base 32 --depth 4`, ~6 млн параметров). Скорость на
  CPU для проверки: `--base 16 --batch 4 --steps 200 --workers 0`.
* Если известны тестовые изображения организаторов, их тип стоит подмешать через `--extra-dir`.
* Баланс PCC/SSIM регулируется `--w-ssim` (больше — выше SSIM, немного ниже PCC).
* Apple Silicon (MPS): комплексные FFT поддерживаются не во всех версиях PyTorch; при ошибке используйте CPU/CUDA.
